系统审计

使用 macOS Endpoint Security，在操作发生时记录执行进程及用户。

未连接

需要 Apple 批准的 Endpoint Security 授权、正式签名、root 辅助程序及完全磁盘访问权限。主界面保持普通用户权限。

没有 Apple 授权时，可用「以管理员方式启动审计」：通过 OpenBSM 审计管道(/dev/auditpipe)采集，输入一次管理员密码即可，记录同样标注「系统审计」并带进程与用户。

审计记录会标注“系统审计”。未连接时仍记录普通文件通知，但不能可靠判断删除者。

记录详情
!

删除全部日志？

当前数据库中的文件事件和监控诊断将被永久删除，无法撤销。此操作不受搜索条件限制。

删除期间暂停本程序监控，完成后恢复原状态。配置与密钥保留。

启用系统审计？

系统审计可以记录实际执行删除等操作的进程与用户。审计辅助程序需要由 macOS 以 root 运行，主界面保持普通用户权限。

  1. 检查 Apple ES 专用授权及应用签名。
  2. 打开系统设置，请管理员批准后台服务。
  3. 如缺少完全磁盘访问权限，自动打开对应设置页面。

管理员验证由 macOS 完成，本程序不接收或保存密码。完全磁盘访问需用户手动开启；Apple ES 授权不能用管理员密码替代。
